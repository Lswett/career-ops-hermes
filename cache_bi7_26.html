The Role
Develop and maintain full-stack web applications using Angular, TypeScript, Java, AWS serverless services, and microservices. Responsibilities include designing, testing, deploying, troubleshooting, optimizing, and reviewing code; participating in Agile sprints; translating requirements into technical solutions; maintaining documentation; and collaborating with architects, product teams, designers, administrators, analysts, and project managers.

ROLE & RESPONSIBILITIES

  • Participate in sprint planning meetings to assign story points and commit to the user stories planned for a given sprint.
  • Implement code using AWS native services and AWS serverless technologies.
  • Design, develop, test, and deploy web applications using Angular and TypeScript, and microservices using Java.
  • Maintain code quality and ensure application responsiveness.
  • Participate in code reviews to ensure code quality and consistency.
  • Optimize application performance and scalability.
  • Stay up to date with emerging trends and technologies in full-stack development.
  • Engage with architects and product teams to understand functional challenges, prototype new ideas and technologies, and help create innovative solutions.
  • Design and develop solutions following established frameworks, application development standards, and quality processes in projects.
  • Perform code reviews and suggest tools, technologies, and best practices that improve stability.
  • Translate requirements into technical specifications and diagrams, and implement them in conformance with architectural and business requirements.
  • Assist with the development and maintenance of operational and system-level documentation.
  • Enhance software to reduce operating time or improve efficiency.
  • Troubleshoot and resolve issues in development, test, and production environments.
  • Collaborate closely with cross-functional teams, including software developers, project managers, UX designers, system administrators, and analysts.

REQUIRED QUALIFICATIONS

  • Proficiency in multiple programming languages (Java).
  • Experience with front-end frameworks (Angular, TypeScript, React).
  • Experience with back-end frameworks (Node.js).
  • Experience in a scripting language (JavaScript, PHP).
  • Database management (DynamoDB, Aurora DB).
  • API development and integration, and DevOps and deployment.
  • Testing and debugging, and security and data protection.
  • Performance optimization.
  • Version control (Git), and Agile and Scrum methodologies.
  • Project management and collaboration tools (Jira, Confluence).

PREFERRED QUALIFICATIONS

  • Any relevant professional certifications.
  • Understanding of front-end-related aspects of relational databases, as well as familiarity with ORM and SQL technologies within the context of Drupal development, is required.
  • Excellent verbal and written communication skills, particularly within the context of front-end development and collaboration with cross-functional teams.
  • Enthusiasm for learning new front-end development tools, languages, design philosophies, and workflows applicable to Drupal development.
  • Experience working with F5 and NGINX is nice to have.
  • Experience with Generative AI and AI-assisted development tools to enhance software development, testing, debugging, and documentation.
  • Familiarity with integrating Generative AI/LLM capabilities into web applications, including AI-powered search, conversational interfaces, or Retrieval-Augmented Generation (RAG).

EDUCATION & CERTIFICATIONS

  • 2 to 3 years of application development.
  • 2 to 3 years of experience developing code using AWS serverless architecture, native services, and containers.
  • 2 to 3 years of experience supporting applications on AWS.
  • Experience working on an Agile project.
  • Experience working on large projects and interacting with several teams within the project.
  • Bachelor's degree in a technical field.
