Role Title: GPU Programmer Software Engineer

Role Type: Contractor

Location: Remote

In this role, you will apply your expertise as a GPU programmer to design GPU related tasks to train LLMs, focusing on performance and architecture.

Required Skills

  • CUDA

  • WebGPU

  • GLSL

  • C++

Scope of Work

  • Design, implement, and optimize GPU-based software solutions using CUDA, WebGPU or GLSL.

  • Profile and fine-tune GPU kernels and shaders for maximum performance and efficiency.

  • Develop host-side logic and integrations in C++

Preferred Qualifications

  • Advanced experience with any GPU programming language that can run on NVIDIA chips.

  • Background in either Graphics Programming, ML acceleration, Scientific Computing, High Performance Computing, or any other domain using GPU technologies.

  • Proficiency in C++

Compensation Structure

Compensation is output-based; experts are paid per task that meets the project specifications. The time required to complete work may vary depending on the expert’s experience and workflow. Minimum submission requirements apply. Experts must submit a minimum of tasks per week.

Start Timeline & Availability

We typically fill roles within 48 hours and are looking for experts ready to jump in right away. If selected, we expect you to start your first tasks within 24–48 hours of completing onboarding.

Skills Required

  • Experience with CUDA
  • Experience with WebGPU
  • Experience with GLSL
  • Proficiency in C++
  • Advanced experience with GPU programming languages that run on NVIDIA chips
  • Background in graphics programming, ML acceleration, scientific computing, high-performance computing, or another GPU technology domain
